# Swim Tracker

A web application for tracking swimming performance data, including personal bests, age bests, meets, and progress graphs.

## Features

- Search for swimmer data by name
- View personal best times across different courses (SCY, LCM, SCM)
- Track age best times
- View meet results and history
- Interactive progress graphs
- Motivational standards and meet cuts
- Rankings by club, LSC, zone, and national level

## Usage

Open `swim.html` in a web browser to use the application.

## Data Source

This application connects to the USA Swimming API to retrieve real-time swimmer data.

## Privacy

This repository is private and contains proprietary swimming data analysis tools.
